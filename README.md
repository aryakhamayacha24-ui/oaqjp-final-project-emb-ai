
# Emotion Detector

## Project Name
Emotion Detector Web Application

## Description
A Python application that uses IBM Watson Natural Language Processing to identify emotions in text. The application detects anger, disgust, fear, joy, and sadness and determines the dominant emotion.

## Technologies Used
- Python
- IBM Watson NLP Emotion Prediction API
- Flask
- Requests
- Unittest
- Pylint

## Features
- Emotion detection from text
- Dominant emotion identification
- Flask web interface
- Input error handling
- Unit testing and static code analysis
